   expected: `matplotlib`, `pillow`, `fonttools`, `contourpy`, `kiwisolver`,
   `pyparsing`, `python-dateutil`, `six`, `absl-py`, `flatbuffers`. The
   TECH-PICK proved the *resolution* was safe but did not enumerate this
   footprint. Nothing here is declared by us and nothing is imported by our
   code, so I did not treat it as a new TECH-PICK trigger — a transitive of an
   approved dependency is not a new dependency. Recording it because a
   ~44 MB OpenCV wheel plus a matplotlib chain is a material footprint change
   in an app whose rule is "offline-only", and a verifier should get to judge
   that rather than discover it.
2. **`uv add` performed a network download.** That is build time, not runtime,
   and follows the F3 ECAPA precedent; the offline rule is about runtime and is
   pinned at source level by Task 4's assertion. Stating it so it is not
   mistaken for a violation.
3. Git reported `LF will be replaced by CRLF` warnings on the committed files.
   Pre-existing repo behaviour on Windows, not something this task introduced.
