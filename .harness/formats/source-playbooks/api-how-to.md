# Source playbook — API facts and how-to

Load this before searching.

1. **Official documentation** — for the version you are actually on, not
   "latest" if they differ.
2. **The source code / type definitions** — the API cannot disagree with
   itself. When docs and source disagree, the source wins; note the discrepancy
   in the findings.
3. **The changelog / release notes** between your installed version and
   current — the gap is where surprises live.
4. Nothing else. A tutorial that doesn't state its version is a rumor.
