# Source playbook — debugging an error

Load this before searching.

1. Search the **exact error message in quotes**. Also try a general description
   of the behavior — novices and experts describe the same bug differently.
2. **GitHub issues** on the library's repo — open AND closed (closed issues
   hold the resolutions). Look for the fix or workaround, not just the
   explanation. Check whether it's version-specific; look for linked PRs and
   patches.
3. **Stack Overflow / Stack Exchange**: accepted and top answers — check their
   dates against your installed version before trusting them.
4. **Official docs / changelog**: was the behavior changed or fixed in a later
   release than yours?

Record in the findings: the cause, the fix, the version range it applies to,
and the source link for each.
