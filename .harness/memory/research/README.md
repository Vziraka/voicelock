# Research findings (cited, dated, append-only)

One file per investigation, written by the `research` skill:
`{YYYY-MM-DD}-{topic}.md` — one claim per line, each with its source link and
the date of the evidence; anything unconfirmable is marked `unconfirmed`
(Gray zone = FAIL — see `formats/source-playbooks/`).

Files here are never edited after writing — a newer file supersedes an older
one. TECH-PICK comparisons and grilling recommendations cite these files
instead of restating them.
