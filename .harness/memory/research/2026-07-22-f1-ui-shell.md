## Fit notes (against VoiceLock constraints)

- Need: desktop window, render existing HTML/CSS/JS booth, Python owns audio/brain, offline-only, small learning project.
- pywebview: light native webview wrapper; matches brain/looks split without shipping Chromium.
- PySide6+WebEngine: live and capable; pulls a full Qt + Chromium stack (large blast radius / install weight).
- Eel: live on recency; Alpha; Chrome/Electron-like path conflicts with prior stack preference against Electron/TS-first weight.

## Delta vs first instinct

First instinct was pywebview. Research confirmed it is live and widely downloaded; PySide6 is also live but heavier than this learning booth needs. Eel clears recency but Alpha + Chromium path make it a weak fit.
